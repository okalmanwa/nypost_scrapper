New York Post archive

Collect articles

Each person has a fixed range of publication years. Choose your name to see your years, then run fetch, scrape, or clean.

Pipeline

  1. Fetch builds a list of article URLs from the archive.
  2. Scrape downloads each page (only those years).
  3. Clean strips boilerplate and filters rows.

Dependencies

When you start the app (python workflow_app.py), it runs pip install -r requirements.txt using this Python so fetch, scrape, clean, and the web UI packages are present. If pip is missing, the app tries python -m ensurepip first; on some Linux installs you may need your distro’s python3-pip package. To skip auto-install, set NYPOST_WORKFLOW_SKIP_PIP=1.

If you pause

  • Fetch and scrape can be run again; they skip finished work.
  • Clean should be run again from the start if it was interrupted.

Output files are saved under results/ using your first name. Command-line details are in README.md. Dependencies install automatically when the server starts.
